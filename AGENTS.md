# Workspace context

Use `.kimi/context.md` as the persistent, concise memory for work in this workspace.

- Read it when starting a task or when prior project context is needed; do not reload it unnecessarily.
- Keep stable facts, decisions, current state, relevant file paths, and verification results there instead of relying on long chat history.
- Update it when information changes or a task produces details useful to later sessions. Keep entries dense and remove obsolete or duplicate information.
- Do not store secrets, credentials, full transcripts, or large excerpts that can be read from source files on demand.
- Apply this workflow throughout this workspace, including subdirectories.
